# QR-Scanner

## Overview

**QR-Scanner** is a Windows desktop application built with C# and the .NET Framework. It provides a simple and efficient interface for scanning and decoding QR codes using a connected camera or image files. The application is designed to help users quickly extract and use QR code data for various purposes, such as URLs, contact information, product IDs, and more.

## Features

- Real-time QR code scanning using a webcam
- Automatic detection and decoding of QR codes
- Copy decoded text to clipboard
- Clean and responsive Windows Forms UI
- Lightweight and fast performance

## Requirements

- Windows 10 or later
- [.NET Framework 4.7.2](https://dotnet.microsoft.com/en-us/download/dotnet-framework/net472) or newer
- Webcam (for live QR scanning)

## Getting Started

1. **Clone the Repository**

   ```bash
   git clone https://github.com/isharaimagines/QR-Scanner.git
   ```

2. **Open the Solution and Run**

   Go to `Setupr/Debug` and run `setup.exe`file

3. **Debug or Edit**

   Open the `QR-Scan.sln` file in Visual Studio.

## Usage

1. Launch the application.
2. Choose whether to scan a QR code from a live camera feeds.
3. View the decoded information instantly.
4. Use the provided options to copy or export the scanned data.
